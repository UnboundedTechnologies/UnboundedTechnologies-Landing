## Problem

BMO's Personal and Business Banking group needed a branch application that gives clients the best term pricing on banking products. This is an active enterprise engagement under non-disclosure, so public details are kept minimal and specific figures are not published.

## Approach

As the sole backend engineer, I designed and built the backend from scratch on multi-account AWS, using infrastructure as code. Jest coverage gates in the release pipelines, Playwright automation and AI engineering tooling (RAG, agents, multi-model pull request reviews, smoke tests and infrastructure verification) support every release.

## Outcome

The application moved from pilot to national deployment across BMO branches in Canada. I also became a reference for Senior Technical Officers on other projects' first production deployments, covering code reviews, compliance, readiness analysis, deployment and post-release API verification. The engagement is ongoing.
