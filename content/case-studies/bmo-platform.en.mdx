## Problem

BMO's Personal and Business Banking group needed a branch application that gives clients the best term pricing on products such as RRSP, RIF and TFSA, based on term length and other factors. It had to meet banking standards for security, compliance and release control.

## Approach

As the sole backend engineer, I designed and built the backend from scratch on multi-account AWS with Lambda, API Gateway, RDS, EventBridge and S3, using BMO's AWS CDK framework and CloudFormation. I also delivered 33% of the UI tickets. Service-to-service calls to upstream APIs use Cognito tokens instead of API keys, for security and compliance.

Release pipelines will not run below an 85% Jest coverage gate on backend and frontend, and the product holds around 95%. Playwright automation supports QA, and AI engineering tooling covers RAG, a Claude Code and ChatGPT pull request review agent, deployment automation, API smoke tests and CloudFormation verification.

## Outcome

The application moved from a 600-user pilot to national deployment across all BMO branches in Canada, and is listed among the main apps on BMO's employee portal. Stress and penetration testing came before release: 8-hour runs at 70%, 90% and 100% load recorded only 4 failed transactions out of 150,000+ (99.997% success). I also became a reference for Senior Technical Officers on other projects' first production deployments, covering code reviews, compliance, readiness analysis, deployment and post-release API verification. The engagement is ongoing.
